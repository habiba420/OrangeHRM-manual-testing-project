🧪 OrangeHRM – Manual Testing Project
📘 Overview
OrangeHRM is a web-based Human Resource Management system that helps organizations manage employee information, leave, recruitment, time tracking, performance, and other HR activities.This project focuses on Software Quality Assurance (SQA) by planning, designing, executing, and reporting test activities to ensure the application is functional, reliable, and user-friendly.
🎯 Project Objectives
•	Validate that all major modules work correctly. 
•	Ensure the system performs smoothly across browsers and devices. 
•	Identify and document functional, UI, and usability issues. 
•	Verify proper navigation, validation messages, and data handling. 
•	Confirm the application provides a stable and consistent user experience.

🧪 Types of Testing Performed
Testing Type	Description
Functional Testing	Checks whether each feature works as expected
UI Testing	Verifies layout, alignment, buttons, icons, and text visibility
Usability Testing	Ensures the system is easy to use and navigate
Validation Testing	Checks required fields, error messages, and form rules
Regression Testing	Ensures existing features still work after changes
Smoke Testing	Confirms the basic build is stable for testing
Compatibility Testing	Verifies behavior across browsers/devices

⚙️ Test Approach
•	Manual testing used for key HRM workflows. 
•	Test cases created in Excel/Google Sheets. 
•	Bugs documented with severity, priority, steps, and screenshots. 
•	Basic exploratory testing performed to find unexpected issues. 
•	Retesting and regression testing done after fixes.

⚠️ Risks & Mitigation
Risk	Impact	Mitigation
Demo site downtime	High	Test during stable hours
Limited access to some features	Medium	Focus on accessible demo modules
Incomplete requirements	Medium	Use exploratory testing
Browser-specific UI issues	Medium	Test in multiple browsers
